## 📌 Descripción General

Este repositorio contiene la implementación y entrega de **☕ Object-Oriented Programming Fundamentals in Java (IPC1)**, desarrollado en el curso de **Introducción a la Programación y Computación 1** en la Universidad de San Carlos de Guatemala.
