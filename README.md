# Tablero matemático por consola en Java

Juego de tablero con lanzamiento de dados, avance por casillas y retos matemáticos. Es una práctica de control de flujo y programación en Java, con menú por consola.

## Requisitos

JDK 21 y Apache Ant; el proyecto original es compatible con NetBeans y declara Java 21 en nbproject/project.properties.

## Ejecución

Los comandos parten de la raíz del repositorio, salvo donde se indica otra terminal.

```bash
cd MiPractica1
ant jar
ant run
```

## Recorrido de demostración

Seleccionar juego nuevo en el menú TABLERO MATEMÁTICO, lanzar el dado y seguir las indicaciones de cada casilla. El objetivo es llegar a la casilla 64. También puede abrirse MiPractica1 en NetBeans con JDK 21.
